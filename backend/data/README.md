
# Data Sources

## JobStreet Dataset

- File: `jobstreet_all_job_dataset.csv`
- Source: https://www.kaggle.com/datasets/azraimohamad/jobstreet-all-job-dataset
- Size: ~166MB, 69,024 Malaysian job postings
- Not committed to Git due to file size. Download from Kaggle and place here.

## Modules Data

- File: `modules.json`
- Source: APU BSc Software Engineering programme brochure (2026)

## Skill Taxonomy

- File: `skill_taxonomy.json`
- Source: Derived from frequency analysis of JobStreet ICT jobs. See `backend/scripts/pipeline/taxonomy_analysis.py` (run from `backend/`).

## Evidence

- File: `skill_frequency_evidence.csv`
- Generated by running `scripts/pipeline/taxonomy_analysis.py`

## Generated files (not in Git)

- `live_jobs_cache.json`: JSearch API responses, made by `scripts/live_jobs/fetch_live_jobs.py`. Keep it: it makes `--use-cache` free
- `embedding_cache.npz`: SBERT vectors, rebuilt automatically. Safe to delete
- `jobstreet_clean.csv`: made by `scripts/pipeline/clean_jobstreet.py`

This folder holds data files only. Scripts that create or process them are in `backend/scripts/`.
