
# Data Sources

## JobStreet Dataset

- File: `jobstreet_all_job_dataset.csv`
- Source: https://www.kaggle.com/datasets/azraimohamad/jobstreet-all-job-dataset
- Size: ~166MB, 69,024 Malaysian job postings
- Not committed to Git due to file size. Download from Kaggle and place here.

## Modules Data

- File: `modules.json`
- Source: APU BSc Software Engineering programme brochure (2026)

## Skill Taxonomy

- File: `skill_taxonomy.json`
- Source: Derived from frequency analysis of JobStreet ICT jobs. See `scripts/taxonomy_analysis.py`.

## Evidence

- File: `skill_frequency_evidence.csv`
- Generated by running `scripts/taxonomy_analysis.py`
