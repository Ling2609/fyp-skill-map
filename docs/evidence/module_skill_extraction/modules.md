## 1. Integrated Computer Systems
code: SE-L1-007

Explores hardware and software integration including computer architecture, assembly language basics, input/output systems and embedded computing concepts.

## 2. Game Development Final Year Project
code: GD-L3-002

Final year project: students build a game prototype in a game engine for their chosen specialism, write a game design document, run playtesting and present the prototype in a portfolio.

## 3. Multimedia Applications
code: MM-L2-001

Covers designing and developing multimedia applications combining text, graphics, audio, video and animation, including authoring tools and interactivity.

## 4. Game Development Team Project 3
code: GD-L2-003

A team project where students produce a polished game, focusing on production management, testing, iteration and delivering a workable game product.

## 5. Computing Theory
code: CS-L2-005

Covers the theory of computation including automata, regular languages, context-free grammars, Turing machines, computability and complexity.

## 6. Cyberpsychology
code: CY-L3-009

Examines human behaviour in cyberspace including online behaviour, social engineering, cybercrime psychology and human factors in cyber security.

## 7. VR/AR Design Project
code: MM-L3-007

A project module where students design and build a virtual or augmented reality application using Unity, from concept and prototyping to user testing.

## 8. Probability and Statistical Modelling
code: CS-L2-002

Covers probability theory, probability distributions, hypothesis testing, regression analysis and statistical modelling of data using R or Python.

## 9. Software Testing
code: SE-L2-009

Covers software testing strategies including unit testing, integration testing, system testing and acceptance testing. Topics include test-driven development, automated testing and quality assurance.

## 10. Project in Quantum Computing
code: QC-L3-004

Final year project: students formulate a real-world problem for a quantum computer, implement quantum circuits in Qiskit, run them on simulators, compare the results with a classical approach and present them in a technical report.

## 11. Investigations in Digital Forensics
code: CY-L3-010

The investigation phase of the final year project: students identify a digital forensics problem, review literature and forensic tools, consider the legal rules on evidence and privacy, define how test evidence will be created and handled, and plan the project. The output is an Investigation Report with the aims, objectives, requirements and project plan for the final year project.

## 12. Intellectual Property, Ethics and Legal Issues
code: MM-L2-007

Covers intellectual property including copyright, trademarks, licensing of digital content, and ethical and legal issues in the media industry.

## 13. Introduction to Networking
code: SE-L1-001

Covers fundamental networking concepts including OSI model, TCP/IP protocols, network topologies, IP addressing, subnetting, routing and basic network configuration and troubleshooting.

## 14. Social Psychology
code: CY-L2-004

Introduces social psychology including social influence, persuasion, group behaviour and attitudes, and how they relate to human factors in cyber security.

## 15. Introduction to 3D Modelling
code: GD-L1-007

Introduces 3D modelling including polygon modelling, modelling props and environments, topology and exporting models for game engines using Autodesk Maya or Blender.

## 16. Information Systems Development Trends
code: IT-L3-027

Examines current trends in information systems development including low-code platforms, cloud-based systems, agile delivery, automation and digital transformation.

## 17. Game Level Design
code: GD-L3-009

Covers level design including level layout, pacing, player guidance, gameplay balancing and building and playtesting levels.

## 18. Systems Software and Computing Concepts
code: SE-L1-002

Introduces operating systems concepts including process management, memory management, file systems, concurrency and computer architecture. Covers CPU organisation and system-level programming.

## 19. Introduction to Security and Forensic Technologies
code: IT-L1-001

Introduces information security principles including confidentiality, integrity and availability, common types of cyber attack such as malware and phishing, basic cryptography, user authentication, access control and the steps of a digital forensic investigation.

## 20. Investigations in Internet of Things
code: IT-L3-021

The investigation phase of the final year project: students identify a problem an IoT system can address, review literature and existing devices, gather requirements from users, compare sensors, boards and communication options, and plan the prototype and its field test. The output is an Investigation Report with the aims, objectives, requirements and project plan for the final year project.

## 21. Penetration Testing
code: IT-L3-010

Covers planning and performing penetration tests on networks and web applications using tools such as Nmap, Metasploit and Burp Suite, and writing penetration test reports.

## 22. Behavioural Science and Marketing Analytics
code: DA-L3-003

Applies behavioural science and analytics to marketing including customer segmentation, consumer behaviour, campaign analysis and marketing metrics.

## 23. Social and Collaborative Computing
code: IT-L3-031

Examines social media platforms, online communities and collaboration tools, and how organisations use social and collaborative computing for communication and teamwork.

## 24. Investigations in Artificial Intelligence
code: AI-L3-001

The investigation phase of the final year project: students define a problem an AI model can solve, review literature and existing models, identify a suitable data set, choose evaluation measures, consider bias and fairness, and plan the project. The output is an Investigation Report with the aims, objectives, requirements and project plan for the final year project.

## 25. Quantum Algorithms
code: QC-L3-001

Covers quantum algorithms including Deutsch-Jozsa, Grover's search, the quantum Fourier transform and Shor's algorithm, implemented with Qiskit.

## 26. Internet of Things: Concepts and Applications
code: IT-L3-007

Introduces IoT architecture, sensors and actuators, microcontrollers, IoT communication protocols such as MQTT, and building simple IoT applications.

## 27. Investigations in Data Analytics
code: DA-L3-001

The investigation phase of the final year project: students define an analytics question for a real organisation or domain, review literature and similar studies, identify data sources and permission to use the data, choose analysis methods and plan the project. The output is an Investigation Report with the aims, objectives, requirements and project plan for the final year project.

## 28. Investigations in Multimedia Technology
code: MM-L3-005

The investigation phase of the final year project: students identify a problem a multimedia or immersive application can address, review literature and similar applications, survey the target audience, and plan the content, tools and production schedule. The output is an Investigation Report with the aims, objectives, requirements and project plan for the final year project.

## 29. Principles of Game Design
code: GD-L1-002

Introduces game design including game mechanics, rules, player experience, level design basics, prototyping and game design documents.

## 30. Designing and Developing Applications on Cloud
code: SE-L3-009

Covers cloud application development using AWS or Azure. Topics include serverless computing, cloud-native architecture, microservices deployment, Docker containers and cloud security.
