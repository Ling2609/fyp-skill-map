Decision (her, 30 Sep): only skills the student has count (A8 same skill or SBERT >= 0.8). Related skills
are shown as gaps that build on a skill she has, not counted; a partial credit (0.25-0.5) was rejected
because any value is a judgement that can't be measured without manual labels. Related knowledge still
lifts a job in the Best-fit order through the whole-profile SBERT similarity. Possible later improvement:
an LLM check of related pairs (same / related / different), as in A8.
